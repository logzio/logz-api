<h1 className={"openapi__heading"}>Get all dashboards folders</h1>

<MethodEndpoint method={"get"} path={"/perses-public/api/v1/projects"}></MethodEndpoint>



Returns every folder in the account, sorted by name. Each entry pairs the folder with its dashboards.

The `dashboards` array is filled only when the `withDashboards` query parameter is present; otherwise it is always empty. The parameter works by presence, so `?withDashboards=false` fills it just as `?withDashboards` does.

Calling this endpoint creates the account's root folder if it doesn't exist yet.
