<h1 className={"openapi__heading"}>Update an existing dashboard</h1>

<MethodEndpoint method={"put"} path={"/perses-public/api/v1/projects/{projectId}/dashboards/{dashboardId}"}></MethodEndpoint>



Replaces the contents of a dashboard, writing a new version.

Send the complete document you want stored: `doc.spec` replaces the stored spec in full, so anything you leave out is removed. From `doc.metadata`, only `name` and `tags` are taken; the rest of the stored metadata, including `project`, is preserved.

The response is the new version: `version` is incremented and `id` is a new value, while `uid` stays the same. `createdAt` is the creation time of the new version row, not of the original dashboard.
