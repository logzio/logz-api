<h1 className={"openapi__heading"}>Update an optimizer.</h1>

<MethodEndpoint method={"put"} path={"/v1/triggers/{id}"}></MethodEndpoint>



Replaces an optimizer with the one in the request and returns the updated optimizer. Send the full optimizer, with `id` set to the ID in the URL: start from [Get an optimizer](https://api-docs.logz.io/docs/logz/get-optimizer) and change the fields you need.

Must be run with an API token that has the **User** or **Admin** role. API tokens created before token roles were introduced have the same permissions as Admin.

Please ensure to change the region in the URL to match your account's region.
