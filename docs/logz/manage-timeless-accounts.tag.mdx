Use these API requests to manage timeless accounts, which keep data for as long as you need it. Optimizers write data into them.

Timeless accounts are created in the Logz.io app. For the whole flow, from writing data into a timeless account to cleaning it, see [Manage timeless accounts with the API](https://docs.logz.io/docs/user-guide/integrations/api-cookbook/manage-timeless-accounts-with-the-api).
