<h1 className={"openapi__heading"}>Create a new dashboard</h1>

<MethodEndpoint method={"post"} path={"/perses-public/api/v1/projects/{projectId}/dashboards"}></MethodEndpoint>



Creates a dashboard in the given folder.

The request body wraps a complete Perses dashboard document in a `doc` property. Only `doc.metadata.name` is validated, and it is required: it is the dashboard's identity and the value both search endpoints match on. The title shown in the app is `doc.spec.display.name`. The rest of `doc.spec` is stored as sent, so it has to be a valid Perses dashboard spec for the dashboard to render.

Pass the literal `ROOT_FOLDER` as `projectId` to create the dashboard in the account's root folder, creating that folder if the account doesn't have one yet. This sentinel is accepted on this endpoint only; every other endpoint takes the folder's `id`.

The server sets `doc.metadata.project` from the path, so any value you send for it is replaced.

The dashboard comes back with `version` 1 and the same value for `id`, `uid` and `name`. Those three diverge as soon as the dashboard is updated, so store the `uid`.
